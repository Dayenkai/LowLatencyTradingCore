Then add these in phase 2 for ITCH :

Once the core book works:

F -> Add Order with MPID Attribution
C -> Order Executed With Price
P -> Trade
Q -> Cross Trade
B -> Broken Trade
H -> Stock Trading Action

Why?

F is basically an A plus market-participant attribution.

C covers executions where the execution price must explicitly be published.

P represents certain trades that aren't represented as executions against visible displayed orders.

Q is a Nasdaq cross trade.

B busts/breaks a previously reported trade.

H tells you things like:

AAPL HALTED
AAPL TRADING
